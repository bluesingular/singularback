🚨 10 hard rules

Violating any of these will cost more time to fix than the shortcut saved.

Rule 1 — GDPR is a code invariant
gdpr_required:true → routeModel() throws if model is not Mistral EU. Test: yarn test --grep "GDPR routing" before every commit.
Rule 2 — Credentials never reach LLM
Vault decrypts server-side only. LLM receives clean, pseudonymised content. Lint rule: no credential variables under llm/.
Rule 3 — Quality gates are mandatory
Every external action passes runGates() + validateOutputSchema(). No bypass path. Not for testing, not for admin, not for demo.
Rule 4 — Audit trail immutable at DB level
DB RULE prevents UPDATE/DELETE on audit_entries. Test: direct DELETE must fail at DB level, not application level.
Rule 5 — Task context never truncated
Runtime assertion in assembleContext(): if task layer truncated → throw. Compress in order: outputs → memory → DNA. Never touch the task.
Rule 6 — BullMQ idempotency
Every worker safe to run twice. Heartbeat jobId = heartbeat:${agentId}. Double execution without DB transaction = bug.
Rule 7 — Approval flow non-negotiable
requires_approval → approval_requests record → wait for explicit human confirmation. Auto-executing before approval = bug.
Rule 8 — Company isolation
company_id from auth middleware only. Never trust client-supplied. Every DB query must include WHERE company_id = ?.
Rule 9 — All UI copy from EMOTIONAL_LAYER.md
No English strings in user-facing UI. No invented copy. Find the exact string in EMOTIONAL_LAYER.md first. grep for English in ui/src/pages/ → fail review.
Rule 10 — Seed tasks indistinguishable from real work
No "Test Candidate" or "Sample Company". Anonymised from real domain data, sector-matched. If operator can tell it's a demo → it has failed.
